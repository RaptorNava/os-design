## Ответы на вопросы
1. Разница между su и sudo: su переключает сессию на другого пользователя (требует его пароль), а sudo выполняет разовую команду с правами суперпользователя под паролем текущего пользователя.
2. В Ubuntu вход под root по умолчанию заблокирован в целях безопасности для предотвращения подбора пароля и ведения точного логгирования действий через sudo.
