# Практическая работа № 3 - Вариант B

## Выполненные задачи
1. **ptree.py**: обход `/proc` с извлечением PID, PPID, статуса, RSS и имени команды.
2. **runner.py**: параллельный запуск команд через `os.fork` и `os.execvp` с ожиданием через `os.waitpid`.
3. **Зомби и сироты**:
   - `zombie.py` демонстрирует процесс в состоянии `Z` из-за отсутствия вызова `wait()`.
   - `orphan.py` показывает, как процесс-сирота переходит под опеку `systemd` / `init` (PPID становится равным 1 или системному менеджеру).
4. **COW (Copy-on-Write)**: `lazy_mem.py` доказывает, что память при `fork` копируется лениво — RSS ребенка скачкообразно вырастает только в момент записи в память.
