# Практическая работа № 6 - Синхронизация (Вариант B)

## 1. Выполненные задания
- Реализована задача **«производитель–потребитель»** с кольцевым буфером на 5 элементов с использованием мьютексов и условных переменных (3 производителя, 2 потребителя, 1000 элементов). Инвариант уникальности проверен через `assert`.
- Реализован кастомный **барьер** на условной переменной для 4 потоков в три фазы.
- Продемонстрирована проблема **потерянного пробуждения** (опасность использования `if` вместо `while` перед `wait`).

## 2. Контрольные вопросы
1. **Чем семафор со значением 1 отличается от мьютекса на практике?**
   - Мьютекс имеет концепцию *владения*: освободить мьютекс может только тот поток, который его захватил. Семафор же является механизмом сигнализирования и не имеет владельца — поток может захватить семафор, а другой поток может его освободить.
2. **Почему условную переменную нельзя использовать без мьютекса?**
   - Условная переменная тесно связана с разделяемым состоянием (предикатом). Мьютекс необходим для атомарной проверки предикта и безопасного изменения состояния до ухода в ожидание в `wait()`, чтобы избежать гонок.
