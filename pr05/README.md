## 2. Анализ для набора set3
Для набора `set3` (содержащего один очень длинный процесс и много коротких) наилучшим алгоритмом является **SRTF** (или SJF), так как он пропускает короткие задачи вперед («convoy effect» устраняется), что резко снижает среднее время ожидания и оборота. FCFS заставляет все короткие задачи ждать завершения гигантского первого процесса.

## 3. Контрольные вопросы
1. **Почему SJF нельзя применять в реальной ОС напрямую?**
   - В реальной системе заранее неизвестно время выполнения (burst time) каждого произвольного процесса.
2. **Что происходит при кванте RR, стремящемся к бесконечности?**
   - Алгоритм Round Robin вырождается в классический алгоритм **FCFS (First-Come, First-Served)**.
